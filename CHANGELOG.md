# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2024-XX-XX

### Added
- CMake build system support for cross-platform compatibility
- Enhanced settings management with persistent configuration storage
- Improved volume control popup interface
- Style management system for easier theme customization
- Better file path handling across operating systems

### Changed
- Complete project restructuring from qmake to CMake
- Optimized music file loading mechanism
- Improved playback control logic
- Enhanced UI responsiveness and visual feedback
- Updated icons and visual elements

### Fixed
- Music paths persistence issues across sessions
- Volume control behavior on different platforms
- UI scaling issues on high-DPI displays
- File handling on different operating systems
- Performance bottlenecks during playlist loading

## [1.1.0] - 2023-12-11

### Added
- Basic music player functionality
- Simple playlist management
- Basic playback controls
- Sequential and loop playback modes

### Changed
- Initial public release
