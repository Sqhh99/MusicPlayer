# Music Player v2.0 Release

We're excited to announce Music Player v2.0, a major update that brings significant improvements to our desktop music player application!

## Major Improvements

### CMake Build System
The biggest change in v2.0 is the migration from qmake to CMake, providing:
- Better cross-platform compatibility
- Improved build configuration and dependency management
- Easier integration with modern C++ development workflows
- Enhanced portability across different operating systems

### Enhanced User Experience
- **Improved UI**: Refined interfaces with better visual feedback
- **Volume Control**: Enhanced volume popup with smoother controls
- **Settings Management**: Persistent configuration storage using QSettings
- **Performance**: Faster loading times and smoother playback

### Code Architecture
- **Modern Structure**: Reorganized codebase following contemporary C++ practices
- **Style Management**: Centralized theming system for consistent visuals
- **Settings Handling**: Robust configuration handling with cross-platform path management
- **Resource Management**: Improved handling of music files and application resources

## Breaking Changes
- This version uses a different build system (CMake)
- Project structure has been completely reorganized
