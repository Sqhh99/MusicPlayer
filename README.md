# Music Player

A modern music player application built with Qt 6 and CMake.

## Features

- Music file browsing and management
- Playback controls (play, pause, previous, next)
- Volume control
- Multiple playback modes (sequential, loop)
- Music library management
- Customizable settings

## Requirements

- Qt 6.0 or higher
- CMake 3.16 or higher
- C++17 compatible compiler

## Building from Source

1. Clone the repository:
```
git clone https://github.com/Sqhh99/MusicPlayer.git
```

2. Create a build directory:
```
mkdir build && cd build
```

3. Configure with CMake:
```
cmake ..
```

4. Build the project:
```
cmake --build .
```

5. Run the application:
```
./MusicPlayer  # Linux/macOS
MusicPlayer.exe  # Windows
```
